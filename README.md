## 🛠️ Tecnologias & Ferramentas do Portfólio

O desenvolvimento deste site seguiu as melhores práticas de semântica e estilização para garantir performance e responsividade:

* **Front-end:** HTML5 semântico, CSS3 (com Grid, Flexbox, transições fluidas e efeitos hover dinâmicos) e JavaScript.
* **Tipografia & Estilo:** Uso da fonte *Roboto* para legibilidade e paleta de cores moderna com contrastes de azul e transparências sofisticadas.
* **UX/UI:** Botões integrados de alta usabilidade para **visualizar ou baixar meu Currículo em PDF** com apenas um clique.
